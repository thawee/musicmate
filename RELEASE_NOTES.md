# MusicMate 3.27.0

**From File** can now read tags from folder names as well as the file name. The sheet shows the file name with its two parent folders, for example `Queen / A Night at the Opera / 11 - Bohemian Rhapsody`, so you can see what your pattern has to match. Use `/` for each folder, as in `%artist%/%album%/%track% - %title%`; there is a `/` button and ready-made folder presets. From File now starts with the pattern that fits your files best, and `%track%` only matches numbers, so a name without a track number is no longer misread.
